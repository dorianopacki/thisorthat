## Notes

Roadmap slice: S-08 (`context/foundation/roadmap.md`), PRD ref: FR-003 (część graficzna), NFR §mobile, NFR §izolacja danych. Prerequisites: S-01, S-02. Tracker: GitHub issue #13.

- Outcome: autor może dodać do badania warianty graficzne zamiast lub obok tekstowych, a uczestnik ogląda je na ekranie telefonu; grafiki są dostępne wyłącznie dla autora badania i osób z ważnym linkiem.
- Risk: jedyny plasterek dokładający magazyn plików; niepublikowane grafiki muszą być chronione tą samą regułą co reszta badania — publiczny odczyt z magazynu wykluczony.
- Unknown: limit liczby i rozmiaru grafik na badanie (Open Roadmap Question 2) — bez odpowiedzi plan przyjmie ostrożny limit.
