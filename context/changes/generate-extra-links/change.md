## Notes

Roadmap slice: S-07 (`context/foundation/roadmap.md`), PRD ref: FR-019. Prerequisites: S-01, S-04. Tracker: GitHub issue #12.

- Outcome: autor może dogenerować dodatkowe jednorazowe linki w trwającym badaniu (podnosi N i przesuwa moment automatycznego zamknięcia); badania zamkniętego nie da się rozszerzyć.
- Risk: postęp „X z N" (S-03) i automatyczne zamknięcie (S-04) muszą przeliczać się na bieżąco, nie na wartości z momentu startu.
- Limit z S-01: N (`participant_target`) 1–100 obejmuje łączną liczbę linków — dogenerowanie musi go respektować.
